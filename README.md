# MAX Chat

Веб-чат для отправки и получения текстовых сообщений в MAX через GREEN-API. React, TypeScript, Vite.

## Запуск

Нужен Node.js 20+.

```
npm install
npm run dev
```

Адрес выведется в терминале, обычно это http://localhost:5173.

## Использование

1. В консоли GREEN-API создайте инстанс MAX и авторизуйте его по QR-коду.
2. В настройках инстанса включите «Получать уведомления о входящих сообщениях и файлах», иначе ответы не придут.
3. В приложении введите idInstance и apiTokenInstance. apiUrl берётся со страницы инстанса, если он отличается от api.green-api.com.
4. Нажмите «+», введите номер получателя (например, 79991234567) и создайте чат.
5. Напишите сообщение. Ответ получателя появится в чате сам.

Получатель должен быть другим аккаунтом MAX, не тем, к которому привязан инстанс.

## Как это работает

Номер превращается в chatId методом checkAccount, сообщения уходят через sendMessage. Входящие приложение получает циклом receiveNotification и после обработки удаляет их через deleteNotification. Показываются только текстовые сообщения.

Токен хранится в sessionStorage и пропадает при закрытии вкладки, в коде и репозитории ключей нет.
